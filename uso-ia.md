# Documentación del uso de IA

La IA se utilizó como herramienta de apoyo durante el proyecto, principalmente para ordenar ideas, revisar errores y consultar buenas prácticas. El código final fue revisado y adaptado para entender qué hace cada parte.

## Prompt 1 - Planificación

**Prompt utilizado:**

> Estoy haciendo un Proyecto Integrador de Full Stack Módulo 1. Necesito crear un generador de paletas con HTML, CSS y JavaScript. Debe tener un botón para generar, selector de 6, 8 o 9 colores, formato HEX o RGBA, render dinámico y feedback visual. Proponeme una estructura simple de archivos y un orden de trabajo adecuado para alguien que está aprendiendo frontend.

**Resultado utilizado:**

La respuesta sirvió para separar el proyecto en HTML, CSS y JS y priorizar primero el funcionamiento del botón y la generación de colores.

## Prompt 2 - JavaScript

**Prompt utilizado:**

> Explicame de forma sencilla cómo generar un color HEX aleatorio con JavaScript usando Math.random(), un array o una cadena de caracteres y un for. Quiero entenderlo antes de implementarlo.

**Resultado utilizado:**

Se utilizó la explicación para crear una función pequeña llamada `generateHex()`.

## Prompt 3 - Accesibilidad

**Prompt utilizado:**

> Revisá estos requisitos de accesibilidad para una aplicación web básica: labels asociados, foco visible, contraste y feedback con aria-live. Explicame qué debería revisar sin agregar librerías.

**Resultado utilizado:**

Se incorporaron labels, `:focus-visible`, `aria-live` y una estructura HTML semántica.

## Prompt 4 - README

**Prompt utilizado:**

> Ayudame a armar un README sencillo para un proyecto de estudiante de Full Stack Módulo 1. Tiene que explicar qué hace la aplicación, cómo ejecutarla, estructura, decisiones técnicas, Git y GitHub Pages. Evitá lenguaje demasiado formal.

**Resultado utilizado:**

La estructura del README se utilizó como base y después se adaptó al proyecto.

## Reflexión personal

La IA se usó como apoyo y no como reemplazo de la práctica. Antes de incorporar una sugerencia, se revisó qué parte del código modificaba y para qué servía. Esto fue especialmente útil para ordenar la lógica de JavaScript y revisar accesibilidad.
